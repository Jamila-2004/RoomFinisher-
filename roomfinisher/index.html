A-102 · C# · WPF · Revit API

Every room in the model,
as one editable schedule.

A production-quality Revit 2025/2026 add-in that loads every room into an editable, Excel-like schedule — bulk edit, templates, validation, analytics, and an AI finish assistant — then pushes every change back to the model in a single transaction.

Load all rooms→Edit in schedule→Validate→One transaction to Revit
Features

What the add-in does

01 · Schedule

Excel-like editing

Every room loads into an editable grid, with bulk edit across many rooms at once.

02 · Templates

Templates & validation

Apply finish templates and check the results for errors before anything touches the model.

03 · Analytics

Analytics

Summaries of finishes across the project, so you can review the whole building at a glance.

04 · AI

AI finish assistant

Claude / Gemini assist with finish suggestions, with the architect staying in the loop.

05 · Write-back

Single transaction

All changes are pushed back to Revit together, so one Undo reverses the whole batch.

06 · Architecture

Modeless WPF + ExternalEvent

MVVM design on .NET 8. The window stays open while you keep working in Revit.
